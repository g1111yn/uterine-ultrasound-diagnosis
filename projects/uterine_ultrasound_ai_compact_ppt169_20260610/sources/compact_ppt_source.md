# 子宫超声辅助诊断系统：紧凑汇报源材料

## 项目定位

本项目是面向医院妇科超声检查场景的 AI 辅助诊断系统。系统接收 JPEG、PNG、BMP、TIFF 与 DICOM 超声图像，结合检查方式和检查所见文本，输出正常、子宫内膜癌、息肉三类预测概率。系统支持医生单例推理，也支持 ZIP 批量推理，覆盖病例创建、患者级聚合、逐图热力解释、PDF 报告、历史检索、用户认证、审计日志与运维监控。

## V2 模型方法

当前 V2 模型是图像主导的多模态融合架构。图像侧采用 EfficientNet-B3，输入图像统一 resize 到 300×300，并使用 ImageNet 均值方差归一化，输出 1536 维图像特征。文本侧采用阿里达摩院医学 BERT `nlp_corom_sentence-embedding_chinese-base-medical`，将检查方式与检查所见经训练一致的 `clean_check_project` / `clean_check_seen` 清洗后拼接，取 CLS 向量作为 768 维文本特征。空文本时文本向量为 768 维零向量，系统退化为图像主导推理。

融合层为 `ImageDominantGatedFusion`：图像特征和文本特征分别投影到 256 维隐空间，门控网络根据两路特征产生 0 到 1 的 gate，融合特征为 `gate × image + (1-gate) × text`，再与图像投影拼接形成 512 维分类输入。分类器结构为 512 → 256 → 3，输出 softmax 三分类概率。推理使用 Fold 3 EMA 权重，训练数据规模为 10,587 例患者、196,255 张图像，5 折交叉验证，记录患者级准确率 pat_acc=0.8600。

## 患者级推理与解释

系统以患者为单位组织推理。单例推理允许医生上传 1 到 30 张图像，后端为每张图建立独立 per-image task；所有图像推理完成后，聚合任务生成患者级诊断。聚合策略可插拔，包括 `mean`、`max_severity` 与 `majority_vote`。每张图像保留概率分布、预测类别、置信度、模型版本和推理耗时，并通过 Grad-CAM 对 EfficientNet-B3 最后卷积层生成关注热力图，帮助医生理解模型判断依据。

## 异步队列与批量推理

后端采用单后台 worker 的优先级推理队列，串行化模型调用，避免模型线程安全风险。单例任务优先级为 0，批量任务优先级为 5，因此医生的即时操作可以在批量处理间隙插队执行。单例接口返回 202 与 `task_id`，前端轮询 `/api/tasks/{task_id}`，完成后读取 `/api/cases/{case_id}`。

批量推理入口接收 ZIP，其中包含 `manifest.csv` 与按 `patient_no` 命名的图像目录。批量流水线包含 ZIP 安全解压、zip-bomb 防护、manifest 字段校验、列名拼写提示、重复病人号提示、文本截断、目录匹配、每用户并发批量限制与全局队列限制。批量任务按患者串行处理，每位患者内部按图像逐张进入优先级队列，实时更新 `completed_images`、`completed_patients`、当前患者和 ETA。任务支持取消，服务重启时会将未完成批量任务标记失败，避免长期卡住。

## 工程能力与临床工作流

前端由 React、TypeScript、Vite 与 Tailwind 构建，覆盖登录、单例推理、批量推理、批量历史、批量详情、病例历史、病例详情、医生判断、用户管理、审计日志与运行统计。后端由 FastAPI、SQLAlchemy、SQLite WAL、PyTorch、Transformers、ReportLab、pydicom 与 structlog 支撑。

系统保存原始上传、DICOM 预览、Grad-CAM 图、逐图预测和患者级预测。病例历史支持关键词、日期、预测类别和来源筛选；批量详情展示左侧患者列表、颜色标签、右侧逐图详情与分类汇总条形图。认证采用 bcrypt、HttpOnly + SameSite Cookie、连续失败锁定、强制改密；审计日志记录登录、登出、创建病例、用户管理等操作，并支持 CSV 导出。运维侧提供 `/api/health` 与 `/api/metrics`，包含模型加载状态、队列长度、平均延迟、P95 延迟、数据库体积、病例数、用户数、5xx 与认证失败统计。
