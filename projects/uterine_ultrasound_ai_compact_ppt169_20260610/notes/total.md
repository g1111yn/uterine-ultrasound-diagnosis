# 01_项目总览

这个项目的核心，不是做一个离线分类模型，而是把妇科超声诊断所需的图像输入、检查文本、患者级聚合和临床工作流整合成一套可部署系统。它支持常见图像格式和 DICOM，输出正常、子宫内膜癌、息肉三类概率。模型训练使用一万多例患者、接近二十万张图像，当前推理权重采用 Fold 3 的 EMA 版本。对医生来说，它既能做单例即时推理，也能处理批量 ZIP，后续还接入 Grad-CAM、报告、历史检索和审计。

# 02_V2多模态方法

V2 模型的关键设计是图像主导的多模态融合。图像侧用 EfficientNet-B3，把统一预处理后的超声图像编码成一千五百三十六维特征；文本侧把检查方式和检查所见按训练一致的规则清洗后输入医学 BERT，取 CLS 向量。融合层不是简单拼接，而是先把图像和文本投影到同一隐空间，再用 gate 决定图像证据和文本上下文的比例。这样在文本缺失时系统可以退化为图像推理，在文本可用时又能补充检查语境。

# 03_单例与批量推理流程

工程实现上，最重要的是单例体验不被批量任务拖住。后端把模型调用放进一个优先级队列，由单 worker 串行执行，避免模型线程安全问题。单例任务优先级为零，批量任务优先级为五，所以医生临时提交的病例可以在批量处理间隙插队。批量任务本身按患者逐个推进，ZIP 会经过安全解压、manifest 校验、限流和取消控制。每个患者的多张图完成后，再用 mean、max severity 或 majority vote 生成患者级诊断。

# 04_临床闭环与工程保障

最后一页强调系统的临床闭环。模型输出本身只是第一步，真正能进入医院流程，还需要解释、报告、权限、审计和运维指标。病例详情中保留逐图预测和 Grad-CAM，医生可以给出最终判断，系统也能导出中文 PDF 报告。安全上使用 bcrypt、HttpOnly Cookie、失败锁定和强制改密；管理侧记录审计日志并支持 CSV 导出。运维侧通过 health 和 metrics 观察模型加载、队列长度、平均延迟、P95 延迟、数据库规模和错误情况。
