## IX. Content Outline

### Part 1: Compact Project Brief

#### Slide 01 - 项目总览

- **Layout**: Left assertion block + right compact capability grid + bottom KPI strip.
- **Title**: 子宫超声辅助诊断系统
- **Core message**: 项目把妇科超声图像、检查文本、患者级聚合和临床工作流整合成一个可部署的 AI 辅助诊断系统。
- **Content**:
  - 面向医院妇科超声检查，支持 JPEG / PNG / BMP / TIFF / DICOM。
  - 输出三类概率：正常、子宫内膜癌、息肉。
  - 支持单例即时推理与批量 ZIP 推理。
  - 训练规模：10,587 例患者 / 196,255 张图像；Fold 3 EMA 权重 pat_acc=0.8600。

#### Slide 02 - V2 多模态方法

- **Layout**: Full-width Nature-style method figure + lower facts row.
- **Title**: V2 模型以图像证据为主轴，文本只在门控中补充上下文。
- **Core message**: EfficientNet-B3 与医学 BERT 通过图像主导门控融合，保留超声视觉证据，同时纳入检查方式和检查所见。
- **Visualization**: generated method figure `fig_model_fusion.png`.
- **Content**:
  - 图像：300×300 输入、ImageNet 归一化、EfficientNet-B3 输出 1536 维特征。
  - 文本：检查方式 + 检查所见清洗拼接，医学 BERT 取 768 维 CLS；空文本为零向量。
  - 融合：两路特征投影到 256 维，gate 生成 `g·image + (1-g)·text`，再分类为三类 softmax。

#### Slide 03 - 单例与批量推理流程

- **Layout**: Full-width workflow figure + two-column implementation notes.
- **Title**: 优先级队列让医生即时操作不被批量任务阻塞。
- **Core message**: 后端用单 worker 串行模型调用，单例任务以 priority=0 插队，批量任务以 priority=5 按患者逐步推进。
- **Visualization**: generated workflow figure `fig_inference_workflow.png`.
- **Content**:
  - 单例推理：上传 1-30 张图，立即返回 202 + task_id，前端轮询任务状态。
  - 批量推理：ZIP 包含 manifest.csv 与患者目录，具备安全解压、字段校验、限流、取消和重启失败保护。
  - 患者级聚合：mean / max_severity / majority_vote 可插拔，保留逐图概率和 Grad-CAM。

#### Slide 04 - 临床闭环与工程保障

- **Layout**: Clinical loop figure + four assurance pillars.
- **Title**: 诊断价值来自模型、解释、报告、审计和运维的闭环。
- **Core message**: 系统不仅输出概率，还把 Grad-CAM、医生判断、PDF 报告、历史检索、权限审计和运行指标接入临床闭环。
- **Visualization**: generated loop figure `fig_clinical_loop.png`.
- **Content**:
  - 解释：逐图 Grad-CAM 展示模型关注区域，病例详情保留图像级与患者级结果。
  - 使用：历史记录支持关键词、日期、类别和来源筛选；PDF 报告可导出。
  - 治理：bcrypt、HttpOnly Cookie、失败锁定、强制改密、审计日志 CSV。
  - 运维：health / metrics 暴露模型加载、队列、平均延迟、P95、数据库和错误指标。

## XI. Technical Constraints Reminder

1. viewBox: `0 0 1280 720`
2. Background uses `<rect>` elements
3. Text wrapping uses `<tspan>`; `<foreignObject>` is forbidden
4. Transparency uses `fill-opacity` / `stroke-opacity`; `rgba()` is forbidden
5. Forbidden: `mask`, `<style>`, `class`, `foreignObject`, `textPath`, `animate*`, `script`
6. Use only colors, fonts, icons and images declared in `spec_lock.md`
